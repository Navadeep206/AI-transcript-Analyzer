# Hasamex AI Expert Intelligence

AI-powered analysis of three expert-call transcripts for the Hasamex AI Engineer technical case study.

## Phase 1

Project foundation for a React + JavaScript application. Subsequent phases will add transcript ingestion, interview-guide analysis, evidence-backed quotes and timestamps, cross-transcript Q&A, themes, disagreements, validation, and deployment.

## Planned stack

- React
- JavaScript
- Vite
- Gemini API

## Development

```bash
npm install
npm run dev
```
